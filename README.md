# Cadastro

App Android com um formulário de cadastro de pessoas, feito em **Kotlin**.

> Projeto desenvolvido na faculdade, na disciplina de Programação para Dispositivos Móveis (PDM), em 2024.

## Funcionalidades

- Formulário com nome, telefone, e-mail, opção de receber e-mails, sexo, cidade e UF
- Seleção da UF numa lista (Spinner)
- Botão **Salvar**, que monta um objeto `Formulario` e mostra o resumo do cadastro na tela
- Botão **Limpar**, que zera todos os campos

## Tecnologias

- Kotlin
- Android SDK (mínimo API 24)
- View Binding
- Componentes de formulário do Android: EditText, CheckBox, RadioButton e Spinner

## Como rodar

1. Clone o repositório e abra no Android Studio.
2. Rode o app num emulador ou celular com Android 7.0 ou superior.
